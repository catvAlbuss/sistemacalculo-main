# ciclo_completo

Ciclo completo NovaCad + Análisis Estructural: arma (si faltan) las láminas, el modelo de análisis, abre Análisis Estructural en automático (análisis sísmico, revisión E.030, diseño de columnas) y, cuando vuelve el diseño, lo aplica a las láminas. Úsalo para 'estructura y analiza', 'haz todo el ciclo', 'diseña y dibuja', 'proceso completo'.


## Parámetros

Sin parámetros.
