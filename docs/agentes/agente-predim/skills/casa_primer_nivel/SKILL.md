# casa_primer_nivel

Dibuja la planta completa del primer nivel de una casa: muros, puertas, ventanas, ambientes con áreas, ejes, columnas y cotas. Úsalo para cualquier pedido de casa o vivienda.


## Parámetros

| Parámetro | Tipo | Descripción |
|---|---|---|
| `frente` | number | Ancho del terreno en metros (5-20) |
| `fondo` | number | Largo del terreno en metros (10-40) |
| `dormitorios` | integer | 1 a 4 |
| `banos` | integer | 1 a 3 |
| `cochera` | boolean |  |
