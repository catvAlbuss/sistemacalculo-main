# justificar

Explica por qué el agente puso algo en las láminas o en el modelo: la norma y el artículo que lo respaldan (y si está confirmado), de dónde salió el dato (plano, cálculo, dato del proyecto, criterio del despacho, pedido del cliente o supuesto) y qué alternativas había. Úsalo para '¿por qué…?', 'justifica…', '¿en qué norma…?', '¿de dónde sale…?', 'fundamenta el diseño'.


## Parámetros

| Parámetro | Tipo | Descripción |
|---|---|---|
| `tema` | string | Lo que se pregunta (p. ej. 'platea', 'viga 0.30x0.40', 'recubrimiento'). Vacío: todas las decisiones. |
