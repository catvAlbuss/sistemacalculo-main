# dibujar_ejes

Dibuja una grilla de ejes estructurales. x e y son listas de separaciones sucesivas en metros.


## Parámetros

| Parámetro | Tipo | Descripción |
|---|---|---|
| `x` | array | Separaciones entre ejes verticales, ej. [4, 3.5] |
| `y` | array | Separaciones entre ejes horizontales |
