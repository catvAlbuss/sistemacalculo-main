# revisar_laminas

Revisa las láminas de estructuras que dibujó el agente y da un informe corto para el ingeniero: textos encimados (con corregir=true los separa), datos del proyecto que faltan y lo que el agente aún no dibuja. Úsalo si piden revisar las láminas, corregir textos encimados o saber qué falta.


## Parámetros

| Parámetro | Tipo | Descripción |
|---|---|---|
| `corregir` | boolean | true para separar los textos encimados (achica la letra lo necesario) |
