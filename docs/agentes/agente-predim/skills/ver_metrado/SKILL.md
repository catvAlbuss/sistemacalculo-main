# ver_metrado

Lista las partidas del metrado que sacó el agente (ítem, descripción, unidad y total), en corto. Úsalo para comparar con una captura de la planilla Excel del ingeniero: compara partida por partida, señala solo las que difieren más de ±5 % y pregunta antes de cambiar nada. Si aún no hay metrado, primero metrar_estructura.


## Parámetros

| Parámetro | Tipo | Descripción |
|---|---|---|
| `buscar` | string | Opcional: ítem o palabra para filtrar (ej. '02.03.06' o 'columnas') |
