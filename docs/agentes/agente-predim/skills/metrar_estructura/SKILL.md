# metrar_estructura

Saca el metrado de estructuras (movimiento de tierras, concreto simple, concreto armado: concreto, encofrado, acero, curado, ladrillo de techo) de la estructura que dibujó el agente, con el formato de la planilla del despacho. Con excel=true descarga la planilla .xlsx. Úsalo cuando pidan metrado, metrar, cantidades o planilla de metrados.


## Parámetros

| Parámetro | Tipo | Descripción |
|---|---|---|
| `excel` | boolean | true para descargar la planilla de metrados en Excel |
