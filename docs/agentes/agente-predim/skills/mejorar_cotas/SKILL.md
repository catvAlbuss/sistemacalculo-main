# mejorar_cotas

Mejora las cotas de las láminas del agente: despeja los rótulos de elementos que tapan las cadenas de cotas y las medidas (mueve los rótulos, no las cotas, que quedan ancladas a su línea). Úsalo para 'mejora las cotas', 'las cotas se ven encimadas', 'no se leen las medidas'.


## Parámetros

Sin parámetros.
