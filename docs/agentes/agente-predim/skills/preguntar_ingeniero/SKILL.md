# preguntar_ingeniero

Pregunta al ingeniero una decisión de experto con 2 a 4 opciones (se muestran como botones). Úsalo cuando falta un dato o criterio que no puedes deducir ni está en el estado (ej. tipo de cimentación sin estudio de suelos, si el techo lleva losa, qué vista usar). Recomienda una opción y di por qué en una frase.


## Parámetros

| Parámetro | Tipo | Descripción |
|---|---|---|
| `pregunta` | string | La pregunta, corta y concreta |
| `opciones` | array | 2 a 4 respuestas posibles, cortas |
| `recomendada` | string | La opción que recomiendas (una de las opciones) |
| `porque` | string | Por qué la recomiendas, en una frase |
